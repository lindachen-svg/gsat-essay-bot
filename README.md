# ✍️ 紅筆小改｜學測國寫批改機器人

依照大考中心國寫評分原則，幫高中生批改學測國文作文的靜態網站。

🔗 **網站**：https://redpenwriting.github.io/gsat-essay-bot/

## 功能

| 頁面 | 說明 |
|---|---|
| 首頁 | 題庫與批改紀錄卡片（由 `assets/catalog.js` 自動產生） |
| 批改機器人 | 瀏覽器內即時健檢（字數、段落、口語贅詞、常見錯字、半形標點、一逗到底），並一鍵產生可貼給任何 AI 的「批改指令」 |
| 評分標準 | 整理自大考中心歷年公布的國寫閱卷原則 |
| 題庫 | 仿學測題型自擬練習題（知性題、情意題） |
| 批改紀錄 | 固定八區塊格式的批改報告：等級、四面向評語、逐段批註、錯字、升級三件事、示範改寫 |

## 這個專案的重點：`CLAUDE.md`

這個專案的目標不是只做一個網頁，而是建立一套**讓 AI 可以照著持續擴充**的規則：

- **固定的評分標準**：每篇批改都用同一張等級表，分數一定落在區間內。
- **固定的報告格式**：八個區塊、順序固定，AI 複製 `templates/report-template.html` 填空即可。
- **固定的命名與登記**：`pNN`／`rNN` 流水號 + `catalog.js` 登記，首頁自動更新。
- **固定的視覺元件**：只能使用 `style.css` 的變數與 class，新頁面風格一定一致。
- **完成前檢查清單**：AI 每次都要自我檢查。

想新增內容，只要對 AI 說：

> 讀 CLAUDE.md，新增一道情意題，主題是「轉角」。

> 讀 CLAUDE.md，幫我把這篇作文批改成報告，題目是 p01。

## 技術

純 HTML／CSS／JavaScript，無框架、無建置步驟，直接部署在 GitHub Pages。
